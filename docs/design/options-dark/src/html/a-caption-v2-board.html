A · Caption, with more flair

Same tokens, same faces, same flow. The caption signature is turned up: letterboxed screens, the shared caption set as real subtitles under the photos, and results subtitled over the post's first frame.

What changed from the first Caption

Top and bottom bars move to the true-black stage, so each screen reads as a framed picture. The caption editor sits on the stage, each line in its own caption box. Titles step up to 26sp extra-bold. Instagram's steps become numbered caption cues. No new colours, fonts or components.

Tradeoffs

More black means more OLED smear when scrolling. Subtitles over the results photo need a scrim fallback for very bright or busy images. Line-boxed editing text must still behave as one ordinary text field: selection, cursor and TalkBack reading as continuous text are untested.
